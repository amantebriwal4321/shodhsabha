# Citation discipline

Use this when a council, or a single agent, is about to turn search hits into a verdict.

## Steps

1. List claims that quote a fetched page.
2. Drop any sentence whose number or URL is not in that packet.
3. Mark encyclopedia pages as scope, not as the latest study.
4. Write the brief with only the surviving claims, and name what is still open.

## Limitations

This skill does not browse. A matching quote can still be the wrong source for the decision. Publishing the folder on Finch takes a wallet signature in Listing Center. Until then, ShodhSabha loads `skill.json` into the Skeptic and the Scribe at runtime.
